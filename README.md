# ⚡ Image Forge

Compress and convert images right in the browser. Nothing gets uploaded; all processing happens on your device.

## Features
- Batch processing with drag and drop
- Output as WebP, JPEG, or PNG, with quality and max-width controls
- Before and after slider to compare quality
- Size savings per image and in total
- Light and dark themes

## Run it
Open `index.html` in any modern browser. No build step, no install, no server.
